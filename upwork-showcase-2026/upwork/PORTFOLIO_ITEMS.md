# Four ready-to-paste Upwork portfolio entries

All four are synthetic-data technical demonstrations. Keep that disclosure visible in the text and uploaded image. Do not imply they are past client engagements.

### 01 Financial Performance Dashboard | Power BI, SQL & DAX
**Role:** Business Intelligence Analyst | Financial Reporting & KPI Design

**Description:** Designed a financial performance reporting demonstration using synthetic data across six business units. Defined revenue, expenses, operating profit, profit margin, and cost-to-income KPIs. Prepared a clean dataset and reusable DAX measures for implementation in Power BI. The visual preview was rendered in Python; the companion files show the calculations and reproducible workflow. Focus: clear financial reporting, data quality and actionable management insights.

**Tags:** Power BI, Business Intelligence, Data Visualization, Data Analysis, DAX.

### 02 Sales & Conversion Dashboard | Power BI, SQL & Analytics
**Role:** Data Analyst | Sales Performance & Conversion Analytics

**Description:** Built a sales analytics demonstration with synthetic monthly data, covering revenue, conversion rate, average order value, channel performance, and regional comparison. The package includes a visual dashboard preview, reusable CSV dataset, and Power BI-ready DAX definitions. Its objective is to illustrate how reliable commercial KPIs help teams identify trends and prioritize action. Preview created in Python; no real client data was used.

**Tags:** Power BI, Sales Analytics, Data Visualization, SQL, Data Analysis.

### 03 AI Lead Scoring & Predictive Analytics | Python & Machine Learning
**Role:** Data Scientist | Python, Scikit-learn & Predictive Modeling

**Description:** Developed a reproducible machine learning demonstration for prioritizing sales leads using Python and Scikit-learn. Created synthetic prospect records, built preprocessing and logistic regression pipelines, and evaluated the model on a separate test set using ROC-AUC, precision and recall. The dashboard visualizes ranking performance and score distribution. This is a technical proof of concept on fictional data—not a claim of real-world conversion uplift.

**Tags:** Machine Learning, Python, Predictive Analytics, Data Analysis, Scikit-learn.

### 04 Automated Data Cleaning & ETL Pipeline | Python, SQL & Reporting
**Role:** Data Analyst | Data Quality, ETL & Reporting Automation

**Description:** Built a Python data-processing demonstration that standardizes transaction fields, removes duplicate IDs, validates amounts and exports clean records to CSV and SQLite. The project provides reproducible source data, automated quality checks and SQL queries for downstream reporting. It illustrates an end-to-end ingestion-to-reporting workflow for teams working with messy operational datasets. All records and metrics are synthetic.

**Tags:** Python, Data Cleaning, ETL, SQL, Data Processing.
